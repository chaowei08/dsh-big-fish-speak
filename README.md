# dsh-big-fish-speak

让 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 桌宠用**它自己设置页里选的音色**，把模型的输出念出来。

- 不自带语音引擎：文本直接交给本机 dsh-pet，由它用你设的音色合成播放
- 地址直接读 DSH 自己的 webServer 端口，不靠扒桌宠日志摸端口
- 新版桌宠（0.4.6+）整段下发，单次上限 500 字；旧版自动按 60 字切（老版本客户端会截断）
- 每段回读桌宠日志确认真的出了声，失败只跳过那一段
- 零依赖，只访问 `127.0.0.1`，不收集、不上传任何数据

安装包见 [npm](https://www.npmjs.com/package/dsh-big-fish-speak)

## 安装

先装好并**保持运行** [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（0.4.x）。
想整段念长回答，需要 **0.4.6 或更高**：那一版才取消了客户端 60 字截断。

在 DSH 插件页「+ 添加插件」里填包名：

```
dsh-big-fish-speak
```

或命令行：

```
npm i dsh-big-fish-speak
```

想用本地包（自己改过代码、不想走 registry）：在同一个入口填 tgz 路径或源码目录路径。
- 填 **tgz** → 真拷贝进 profile，源文件删了也不影响，但要重装得留着这个 tgz
- 填 **目录** → 装成链接（Junction）指向该目录，改代码即时生效，但**目录一删插件就断**

## 用法

| 命令 | 作用 |
| --- | --- |
| `/speak <文本>` | 让桌宠念这段话（默认念全文） |
| `/voice` | 查看当前音色、音量、自动播报开关 |
| `/voice test` | 试听一句 |
| `/voice auto on\|off` | 开关「模型输出自动播报」 |

自动播报默认开启：监听 `session/event` 的 `assistant/message`，模型一有正文就念。

## 它怎么念

**地址**：桌宠的路由挂在 DSH 自己的 webServer 上，所以插件直接读宿主给的 `ctx.webServer` 端口（`getOrigin()` / `port`），桌宠重启换端口也不会失联。只有端口还没就绪时才退回日志里的地址兜底。

**长度**：桌宠 0.4.6 取消了单句 60 字截断，插件就改成整段一次送出去；但宿主 `/voice/speak` 仍限制单次最多 500 字（`MAX_TEXT_CHARS`），超过才按标点切成几块。

**旧版兜底**：如果装的是 0.4.5 或更早，客户端会把正文截到 60 字——插件按安装的版本号自动切 60 字；万一版本读不到，也会在日志里发现"只念了前 60 字"后即时降级，把剩下的字数接着念完。

**节奏**：确实需要分块时，段间按实测语速衔接（约 0.23 秒/字 + 换气），上一段还在播时下一段已经在桌宠那边并行合成，听感是一句接一句。

**段数**：不设上限，几百上千字都会念完。只有一层极端保护（200 段），正常对话碰不到。

## 合成失败怎么办

桌宠的广播接口回 `ok:true` 只表示「它收到了」，真正合成失败时它只在日志里留一行 `failed`，那一段会静默消失——听感就是念两句突然没了。

插件每送一段都会回读 `~/.dsh/dsh-pet/logs.txt`：确认有新记录 = 这段真念了；是 `failed` = 退避重发，最多 3 次；仍失败只跳过这一段，后面的照念，不会整轮哑掉。最常见的失败原因是 Edge TTS 返回 429 限流。

## config（可选）

写在 `cordis.patch.yml`，一般不用填：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `maxChars` | 跟随桌宠版本（新版 500 / 旧版 60） | 单段字数上限，只能改小 |
| `autoChunks` | 不限 | 自动播报最多几段 |
| `speakChunks` | 不限 | `/speak` 最多几段 |

## 已知限制

- 桌宠不在或没加载完：命令会明确报「找不到桌宠服务地址」
- 桌宠还停在 0.4.5 及更早时，单句只能念 60 字，插件会按 60 字切段（升到 0.4.6 才是整段念）
- 音色、音量、语音播报开关全在**桌宠自己的设置页**里改，本插件不提供设置界面
